# Réveil Raspberry Pi – kxsbpi

Réveil audio pilotable via interface web locale.

## Fonctionnalités

- Réveil programmé (playlist / FIP / aléatoire)
- Fade-in configurable (durée, courbe, volume)
- Interface mobile-first
- Visualisation en temps réel du fade
- Mise à jour automatique playlist (yt-dlp)
- Loudness normalization par piste

## Installation

```bash
git clone https://github.com/kxsb/Reveil_kxsbpi.git
cd Reveil_kxsbpi
```
## Lancer l'app

python3 app.py
